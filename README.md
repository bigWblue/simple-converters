Simple python scripts that convert between different units of measurement with the interface made using the built-in module Tkinter.

# Available Conversions
+ Distance (Meters, Kilometers, Miles, Feet, Yards)
+ Temperature (Celsius, Kelvin, Fahrenheit)
+ Roman Numerals to Arabic Numerals and vice-versa

# Usage
When the window has two dropdown boxes, the one on the left is the input unit and the one on the right is what it will be converted to, for the Roman Numerals one it will output either Arabic or Roman numerals, depending on which you enter.

# Notes
The scripts in this repository are really basic and served as a way of learning how to apply an interface to python scripts and aren't intended to be much more complex.
